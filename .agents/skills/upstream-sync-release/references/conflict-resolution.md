# Upstream Merge & Conflict Resolution Guide

Reference rules for merging `upstream/main` (`wegooo-cell/read-pico-reader`) into this fork (`zhuxiangxiao/read-pico-reader`).

## 1. Upstream Files to Take As-Is

- `flash/**` — Do not customize upstream website archives or release metadata; our fork deploys OTA assets purely to GitHub Pages without modifying `flash/`.
- `boards/pico/board.json` & `boards/metalio47/board.json` — Always accept upstream `version` (`0.3.3-rc...`). `tools/fork_ota_config.py` derives `.1` / `.2` revisions dynamically from GitHub Releases.

## 2. Fork OTA Touchpoints to Preserve

Verify `git diff` keeps our fork guards and 5-part version handling in:

- `.github/workflows/pages.yml` (`github.repository == 'wegooo-cell/read-pico-reader'` guard)
- `.github/workflows/fork-ota-release.yml`
- `CMakeLists.txt`, `main/CMakeLists.txt`
- `main/ota_online.h`, `main/ota_release.c`
- `boards/pico/src/main/ota_release.c`, `boards/pico/src/main/ota_online.c`
- `boards/metalio47/src/main/ota_online.c`
- `tools/build_firmware.py`

## 3. Build Flags & Flash Partition Budget

1. **Sync S31 build flags**: Compare `board_release_flags` between `.github/workflows/build.yml` and `.github/workflows/fork-ota-release.yml` (line ~140). Whenever upstream adds or toggles an S31 release flag (e.g. `--s31-early-power-key`, `--s31-rc110-ripple`), mirror it in `fork-ota-release.yml`.
2. **UI icon compression & cold `-Oz` list in `main/CMakeLists.txt`**:
   - Keep `KIIKO_UI_ICONS_DEFLATE=1` enabled unconditionally for both Pico and Metalio47 (saves ~32 KB per board over RLE and removes need for `ui_icon_unpack.inc` / `ui_icons_packed.h`).
   - Any newly added upstream non-hot `.c` files (such as `book_library.c`, `book_import.c`) must be added to `weread_cold_size_sources` and the `-Oz` regex in `main/CMakeLists.txt` so both Pico (4 MiB app slot) and S31 (5 MiB app slot) maintain comfortable `free_app_bytes` headroom.
   - Avoid duplicate `set_property` / `COMPILE_OPTIONS` loops when merging `main/CMakeLists.txt`.

## 4. WeRead, 5-Tab Navigation & Resume Conflict Patterns

Check both shared (`main/`) and Pico-specific (`boards/pico/src/main/`) copies:

- **`main/boot_state.c`**:
  - Keep `resume_valid` admitting both local tabs (`tab < PICO_BOOT_TAB_COUNT`) and WeRead tab `6` (`book_path_is_weread(r->path)`).
- **`boards/pico/src/main/app_main.c` & `boards/metalio47/src/main/app_main.c`**:
  - Adopt upstream non-blocking startup resume (`if (app_book_request_resume(resume.path, resume.fullscreen, resume.tab)) first = app_at(1);`).
- **`main/ui/ui_kit.c` & `boards/pico/src/main/ui/ui_kit.c`**:
  - Keep upstream `ui_icon_mask(icon)` (`KIIKO_UI_ICONS_DEFLATE=1`).
- **`main/app/app_loop.c` & `boards/pico/src/main/app/app_loop.c`**:
  - Keep `app_book_prepare_leave(ctx)` at top of `prepare_lock`, 5-tab `app_nav_position(tab)`, `app_book_resume_origin()`, and upstream's `position_ready && checkpoint_ready` durability check + `pico_boot_clear_resume()` before power-off/restart handoff (`c15f6bd`).
- **`main/apps/app_dashboard.c` & `boards/pico/src/main/apps/app_dashboard.c`**:
  - In `scan_books()`, check `app_setup_library_pending()` before calling `weread_runtime_load_local()`.
  - In `refresh_progress()`, keep `book_target_stat(item->path, &st)` / `book_progress_load_checked` and guard `ENOENT`/`ENOTDIR` item removal with `!book_path_is_weread(item->path)`.
- **`main/apps/app_book.c` & `boards/pico/src/main/apps/app_book.c`**:
  - Keep `library_member`, `book_library_include(s_path)`, and `s_library_setup_pending = false` guarded with `!book_path_is_weread(...)` so opening `weread://` books never fails enrollment.
  - In `resume_media_wait(ctx)`, wait for `/sdcard/` when `book_path_is_weread(s_requested_open)` too; in `open_requested_book(ctx)`, call `if (book_path_is_weread(path)) weread_runtime_load_local();` before `open_book`.
  - Keep `s_lock_reader_origin` saved in `before_lock` and passed to `app_book_request_resume(..., s_lock_reader_origin)` in `book_on_media_ready`; keep Pico `display_set_rail_hold` in `on_tick`; drop obsolete `s_reader_return_home`.

## 5. Host Test Maintenance Notes

- **`IDF_PATH`**: `weread_http_poll_host_test.py` requires `$IDF_PATH/components/http_parser/http_parser.{c,h}` (available locally at `$HOME/esp/esp-idf`).
- **Materialized tests**: `run_app_loop_host_tests.sh`, `pager_host_test.py`, `ui_pinpad_host_test.py`, and `quick_layer_raster_host_test.py` must run inside `build/host/<board>` generated by `tools/board_source_view.py --board <board> --tests --output build/host/<board>`.
- **Board stub guards**: Keep `app_lock_set_resume_ready` in `tools/app_loop_stubs/sleep.h` under `#else` of `#if KIIKO_BOARD_METALIO47` because `boards/metalio47/tests/tools/app_loop_stubs/common.h` declares it non-static.
- **Extractor stubs**: When upstream adds static state checks inside `app_book.c`, `app_loop.c`, or `app_dashboard.c` functions extracted by host tests (`weread_reader_lifecycle_host_test.py`, `reader_origin_host_test.py`, `pico_home_progress_sync_host_test.py`, `home_initial_empty_host_test.py`, `normal_book_compat_host_test.py`, `reader_resume_durability_host_test.py`, `app_loop_host_test.c`), add matching mock globals/helpers or `__attribute__((unused))` stubs (CI uses Clang/GCC with `-Wall -Wextra -Werror`).
